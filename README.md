# 动保任务小程序（公开源码）

微信原生小程序 + 云开发。底部是「任务」「机动投喂」「我的」；点位、猫档和管理功能收在「我的 → 更多功能」。

管理员有待审核成员时，任务首页显示人数和审批入口，「我的」图标显示数字提醒。底部栏目使用 PNG 图标。

任务页下方有独立的组织任务日历，按审核通过日统计每天完成的任务项数；点日期还能看单列的到岗打卡。机动投喂日历支持给任意猫直接填名字、自动按猫筛选，并给记录附最多 3 张照片。

此仓库是去除真实群聊、成员排班、猫只动态、照片、密码、云环境 ID 和 AppID 的公开源码副本。它不是协会线上数据备份，也不会自动连接线上环境。

## 本地启动

1. 用微信开发者工具导入仓库根目录；把 `project.config.json` 的 `appid` 换成自己的小程序 AppID。
2. 新建云开发环境，并把环境 ID 填入 `miniprogram/config.js`。
3. 按 `database/rules.json` 建立集合规则，部署 `cloudfunctions/login`、`api`、`seed`。
4. 首次登录后，在「我的」使用初始化入口建立演示点位和首位管理员。公开版的排班和猫只种子为空。

真实密码、成员和猫只资料只应在受控云环境里维护，不要写进 Issue、PR 或源码。
